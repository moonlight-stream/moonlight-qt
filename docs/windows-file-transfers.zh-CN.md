# Windows 文件传输变更说明

本次变更配套使用 Moonlight 的 `local-changes` 分支和 Sunshine 的 `moonlight-desktop-integration` 分支。

## 从串流桌面复制到本机

1. 在串流桌面的资源管理器中复制文件。启用剪贴板文件同步后，主机记录所选文件的身份，客户端收到文件名与大小。此时可以在远端继续粘贴，也可以改名或删除源文件。
2. 在本机资源管理器的目标文件夹按 **Ctrl+V**。Sunshine 核对源文件的身份、大小和时间戳，再开始读取。其他软件在主机上改写剪贴板后，只要本机仍保有这次选择、源文件仍能通过校验，就可以粘贴。粘贴前删除源文件并原地新建同名文件，会使原选择失效。
3. 左下角的传输面板显示进度，可以拖动和折叠。每个文件写完就出现在目标目录中。取消任务会清理当前未完成的文件，已经完成的文件可以立即使用。关闭串流后，已启动的独立下载继续运行。任务结束时释放目标目录，结果面板仍可显示。

在本机或串流桌面的资源管理器中粘贴时，会一次列出目标目录里的同名文件。可以统一选择**替换目标中的文件**、**保留副本**（自动编号）或**跳过这些文件**，也可以点**让我决定每个文件**，逐项选择后点**继续**。展开**详细信息**可查看文件名。按 Esc 会跳过本次提示中的所有同名文件，其余文件继续复制。如果目标在传输期间发生变化，会重新确认。直接替换远端文件需要配套的 Sunshine 开启文件浏览和 **Allow file deletion**。连接未实现剪贴板重名提示的主机时，远端粘贴由 Windows 资源管理器处理。

串流中双向复制文件夹需要配套更新 Moonlight 和 Sunshine。剪贴板会保留子目录、空目录和混合选择中的单独文件。粘贴到已有的同名文件夹时会合并内容，原有的其他文件会保留；遇到同名文件时仍可选择替换、保留副本或跳过。剪贴板每次最多选择 32 个顶层项目，展开后最多 4096 个项目。较大的目录树可以通过文件传输助手传输。

## 文件传输助手

- 在已配对的在线主机上打开文件传输助手。两侧文件列表支持排序、复制、粘贴和拖放。双击远端文件会打开临时下载到本机的副本。
- 主机支持独立文件传输时，从串流控制中心打开的文件传输助手也使用独立会话。断开串流后，正在上传、下载和排队的任务会继续。
- 更新 Sunshine 后，只要主机上的 Windows 用户已登录且会话仍连接，锁屏时也可以打开文件传输助手、浏览目录并直接开始上传或下载。文件夹中排队的文件会依次开始传输。与主机资源管理器交互的拖放和直接删除远端文件仍需解锁桌面。
- 文件夹可以在同一侧复制，也可以在两侧之间上传和下载。两端都会合并已有目录。选中文件夹按 **Delete** 后，本机端会将整个文件夹移入回收站，远端确认后会永久删除文件夹和其中的内容。远端删除文件夹需要更新 Sunshine 并开启 **Allow file deletion**。
- 同名冲突可以选择**跳过**、**替换**或**保留两者**。保留两者会寻找可用文件名。替换针对确认时的目标版本。等待确认或恢复传输期间目标发生变化时，原确认失效。
- 替换或永久删除远端文件需要主机启用 **Allow file deletion**。本机删除走回收站。窗口化串流也支持与资源管理器互相拖放。从串流内拖出时使用远程桌面鼠标模式，可按 **Ctrl+Alt+Shift+M** 切换。
- 剪贴板上传根据已确认的吞吐量调整分块，控制通道出现排队时降低速率。设备列表按配对状态分组，并在配对完成后刷新。

## 双机部署与验证

在仓库根目录运行 `python scripts/deploy-streaming.py` 可打开终端菜单。选择本机、CHENX、CX9950X 或多台主机，再选择 Moonlight、Sunshine 或两者。脚本从现有的 Windows Release 构建自动打包，确认后部署。选择「仅校验」可检查安装路径、包哈希和待更新文件数量。执行部署时，更新运行中的 Sunshine 会重启服务，更新正在使用的 Moonlight 会关闭客户端，这可能中断串流。

自动化可使用 `--target local`、`--target remote --host <地址>` 或 `--target all`，并搭配 `--component moonlight`、`--component sunshine` 或 `--dry-run`。完整运行包可通过 `--moonlight-package` 或 `--sunshine-package` 传入。远端通过 SSH 连接并校验已知主机密钥，支持 SSH 密钥、交互密码提示或 `--password-file`。交互密码被拒绝后可重输，留空会跳过该主机并继续处理其他主机。上传进度按实际传输字节显示。安装脚本校验文件 SHA-256、备份被替换的文件，并在该机安装失败时回滚。

| 验证场景 | 结果 |
| --- | --- |
| 实际串流，从远端复制到本机 | 单文件、多文件、中文名和空文件粘贴成功，接收内容的 SHA-256 与源文件一致。 |
| 删除与文件占用 | 粘贴前改名再改回可以正常传输。删除后换成同名文件会被拒绝。结果面板显示期间可以删除已接收的文件。 |
| 客户端回归 | 重名冲突测试覆盖批量替换、保留副本、跳过、逐个选择，以及选择期间目标发生变化。 |
| 主机端回归 | 13 项测试通过，覆盖文件浏览、覆盖与续传、剪贴板文件选择，以及独立传输任务的生命周期。 |
| 双机部署 | 两端分别核对了 Moonlight 和 Sunshine 可执行文件的哈希。服务启动后恢复了原串流，并确认客户端收到视频帧。 |
